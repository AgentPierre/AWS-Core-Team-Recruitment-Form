# BRANDING RULES

## Logo Usage
- Only use the official AWS Cloud Club logo (not the AWS corporate logo).
- Do not stretch, recolor, distort, or modify the Cloud Club logo.

## University Reference
- “University of Houston” may be included as plain text, clearly separated from AWS Cloud Club branding.

## Co-branding Restrictions
- Do not combine logos in a way that implies official AWS partnership or co-branding.
- Maintain clear visual distinction between university text and AWS Cloud Club branding.

## Required Footer Disclaimer
“AWS Cloud Club at the University of Houston is a student-led organization and is not affiliated with or endorsed by Amazon Web Services.”
